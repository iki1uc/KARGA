# KARGA Engine (RESPO-Ort-LAGE)

KARGA = Kern-Achsen-Range-Gewichtung-Auswahl.

Diese Engine findet automatisch:
- die richtige Achse (O, Z, T)
- den richtigen Nummernbereich (001–243)
- den richtigen Modultyp (tmp, vec, re)
- die Verträglichkeit
- die Korrektur
- die Diagnose
- die Speicherung

KARGA basiert auf RESPO-Ort-LAGE:
- ORT = Position
- LAGE = Ebene
- Achse = Richtung
